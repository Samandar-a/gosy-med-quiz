# GOSY MED QUIZ

Готовый тренажер для GitHub Pages.

## Как загрузить на GitHub Pages

1. Создай новый репозиторий, например `gosy-med-quiz`.
2. Загрузи файл `index.html` в корень репозитория.
3. Открой Settings → Pages → Deploy from branch → main / root → Save.
4. Ссылка будет в формате `https://USERNAME.github.io/gosy-med-quiz/`.

## Пароль

Текущий пароль: `gosy2026`

В файле `index.html` пароль хранится в виде SHA-256 хеша. Чтобы поменять пароль, замени значение `PASSWORD_SHA256`.

## Важное про “только одно устройство”

GitHub Pages — это статический сайт. Без базы данных он не может надежно знать, что пароль уже ввели с другого телефона. Поэтому в готовом файле есть 2 режима:

### 1) Local режим
Работает сразу. Пароль есть, но ограничение на одно устройство только локальное, не железное.

### 2) Firebase cloud-lock режим
Это нормальный вариант, чтобы первый вошедший телефон закрепился, а другие телефоны даже с паролем не вошли.

Чтобы включить:
1. Создай Firebase project.
2. Включи Firestore Database.
3. В `index.html` вставь свой `FIREBASE_CONFIG`.
4. Поставь `USE_CLOUD_DEVICE_LOCK: true`.
5. В Firestore Rules на простой тестовый запуск можно поставить правила из файла `firebase-rules.txt`.
6. Чтобы сбросить привязку устройства, удали документ: `quizDeviceLocks/gosy-med-quiz-2026-v1`.
